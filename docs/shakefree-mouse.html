Shakefree Mouse

A tremor-smoothing filter for the mouse pointer, with a tray toggle. It damps small involuntary movements so clicks land where you mean them, without making the pointer feel sluggish for ordinary use.

What it does

  • Real-time smoothing of pointer tremor
  • Tray icon to turn it on and off and tune the strength
  • Leaves fast, deliberate movement untouched

Install

git clone https://github.com/janszafranski/desktop-manager.git ~/system-replica
~/system-replica/profiles/shakefree-mouse/install.sh

Prefer clicking? Everything here also installs from Desktop Manager › Apps. Each tool has an uninstall.sh beside its installer.
