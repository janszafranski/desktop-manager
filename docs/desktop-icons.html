Desktop icons

Puts app icons back on the wallpaper, double-click to open — the desktop you remember, on a tiling Linux setup that normally has none. Arrange them where you like and they stay put.

What it does

  • Clickable app icons on the desktop background
  • Double-click to launch, drag to arrange
  • Works on a tiling window manager that has no desktop of its own

Install

git clone https://github.com/janszafranski/desktop-manager.git ~/system-replica
~/system-replica/profiles/omarchy-desktop-icons/install.sh

Prefer clicking? Everything here also installs from Desktop Manager › Apps. Each tool has an uninstall.sh beside its installer.
