Mic Fixer

A quick microphone tester — speak and watch the level — that helps track down the usual culprit of a too-quiet mic and set it right. Ships the same way as the other tools and lives in profiles/mic-fixer.

What it does

  • Live input-level meter so you can see the mic working
  • Helps find a wrong default device or a gain set too low
  • Installs from Desktop Manager's Apps list, or on its own

Install

git clone https://github.com/janszafranski/desktop-manager.git ~/system-replica
~/system-replica/profiles/mic-fixer/install.sh

Prefer clicking? Everything here also installs from Desktop Manager › Apps. Each tool has an uninstall.sh beside its installer.
