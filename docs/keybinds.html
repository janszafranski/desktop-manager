Keybinds cheat-sheet

An on-screen cheat-sheet of your keyboard shortcuts, for the moment you know there is a shortcut but cannot remember which keys. Summon it, read the one you want, carry on.

What it does

  • Full-screen overlay of your current keybindings
  • Grouped by what the shortcuts do
  • One key to show, one to dismiss

Install

git clone https://github.com/janszafranski/desktop-manager.git ~/system-replica
~/system-replica/profiles/keybinds/install.sh

Prefer clicking? Everything here also installs from Desktop Manager › Apps. Each tool has an uninstall.sh beside its installer.
