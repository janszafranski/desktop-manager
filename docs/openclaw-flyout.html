OpenClaw flyout

An AI assistant that slides in from the edge of the screen — ask a question or hand off a task without leaving whatever you were doing. The panel tucks away again when you are done.

What it does

  • Slide-in side panel bound to a key
  • Stays out of the way until you summon it
  • Talks to your OpenClaw gateway

Install

git clone https://github.com/janszafranski/desktop-manager.git ~/system-replica
~/system-replica/profiles/openclaw-flyout/install.sh

Prefer clicking? Everything here also installs from Desktop Manager › Apps. Each tool has an uninstall.sh beside its installer.
